# Sistema Cognitivo MCP para Inventarios

Proyecto desarrollado para la Actividad 6 - Análisis de datos con sistemas inteligentes de Computación Cognitiva para Big Data.

La aplicación implementa un sistema cognitivo de gestión de inventario utilizando Python, SQLite y MCP, permitiendo realizar operaciones de administración de productos y análisis de datos sobre la información almacenada.

## Tecnologías

- Python 3
- SQLite
- FastMCP
- VS Code
- Google Colab
- GitHub

## Estructura del Proyecto

*database.py*

Archivo encargado de la creación e inicialización de la base de datos SQLite.

*server.py*

Contiene la implementación del servidor MCP y las herramientas para la gestión del inventario.

## Funcionalidades

- Crear productos
- Consultar productos
- Actualizar productos
- Eliminar productos
- Listar productos
- Calcular valor total del inventario
- Detectar productos agotados
- Obtener producto más costoso
- Generar estadísticas generales

## Instalación

Instalar las dependencias necesarias:

*pip install fastmcp*

## Ejecución

Ejecutar el servidor MCP:

*python server.py*

## Pruebas Realizadas

Durante el desarrollo se realizaron las siguientes pruebas:

- Creación de cinco productos.
- Consulta de productos por identificador.
- Actualización de cantidades.
- Eliminación de productos.
- Listado completo del inventario.
- Cálculo del valor total del inventario.
- Consulta de productos agotados.
- Identificación del producto más costoso.
- Consulta de estadísticas generales.

Todas las pruebas fueron ejecutadas satisfactoriamente y permitieron verificar el correcto funcionamiento del sistema.

## Resultados

La implementación permitió integrar una base de datos SQLite con un servidor MCP, demostrando cómo los sistemas cognitivos pueden interactuar con fuentes de datos estructuradas para realizar consultas, análisis y apoyo en la toma de decisiones.
